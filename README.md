**Xiao Huang, Ya Zhang†, Weidi Xie†**  
School of Artificial Intelligence, Shanghai Jiao Tong University  
† Corresponding authors

Project page: https://xiao-0309.github.io/PREM/

The website contains the paper, method overview, benchmark results, and 13 evaluation videos.

## Hosting

This is a static GitHub Pages website. In Settings → Pages, use **Deploy from a branch**, select **main**, and select **/(root)**. No build step is required; `.nojekyll` is included.

## Local preview

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

Open http://127.0.0.1:8767/ in your browser.
